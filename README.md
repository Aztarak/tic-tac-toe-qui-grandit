# Puissance Trois évolutif (serveur)

Aucun compte nécessaire pour jouer : on ouvre le lien, on entre un pseudo et le même code de salle.

## Tester chez toi
    npm install
    npm start
Puis ouvre http://localhost:3000 dans deux onglets.

## Mettre en ligne (exemple : Render, gratuit)
1. Mets ce dossier dans un dépôt GitHub.
2. Sur render.com : New > Web Service, choisis le dépôt.
3. Build command : `npm install` — Start command : `npm start`.
4. Envoie le lien fourni par Render à tes amis.

Sur l'offre gratuite, le serveur s'endort après un moment sans visite : le premier chargement peut prendre une trentaine de secondes. Les parties sont gardées en mémoire et disparaissent si le serveur redémarre.
